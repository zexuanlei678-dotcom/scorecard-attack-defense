# When Scores Lie：信用评分卡的特征操纵攻防研究

信用评分卡是消费信贷审批的事实标准，但它依赖的部分特征可以被借款人在申贷前短期改变。本项目先构建一条完整的标准评分卡流水线，再从**攻击者视角**模拟借款人的"资质包装"行为，量化"分数虚高、真实违约风险不变"造成的评分失真，最后评估三类防御方案的有效性与代价。

选题对应公开课程仓库的置顶issue *FICO个人信用评分*，按其要求交付**算法集、数据集获取方式、测试报告**。

## 核心研究问题

1. 评分卡的哪些输入特征最容易被操纵？操纵成本与分数提升如何权衡？
2. 被操纵后通过审批的客户，其真实违约率相对正常客户高出多少？
3. 稳健评分卡、突变检测、对抗训练三种防御，分别以多大的性能代价换取多少抗攻击能力？

## 主要结论

基于Give Me Some Credit数据集（测试集37500样本）：

- 基线评分卡区分能力良好：AUC=0.858、KS=0.560、训练/测试PSI=0.0004；正常审批通过客户的坏账率为1.09%。
- 强组合攻击（利用率、债务比、逾期记录同时包装）使平均评分上涨24分，**46.1%的原被拒客户翻转通过**，审批通过率从49.7%升至95.6%。
- 这些攻击得手客户的真实坏账率为**9.92%，约为正常通过客户的9.1倍**，构成机构的隐藏坏账。
- 单特征攻击中，信用利用率操纵最脆弱（满强度翻转率25.8%）；逾期记录洗白所获客户的真实坏账率最高（9.65%）。
- 防御方面：剔除高可操纵特征的稳健评分卡把翻转率从46.1%压到6.6%，AUC仅损失0.031，性价比最高；对抗训练将翻转率降至36.4%且得手客户坏账率降至3.63%；基于历史快照的突变检测对强攻击检测率达100%、干净样本误报1.0%，但对无历史数据的新客户失效。

外部验证集（UCI台湾信用卡数据）上结论方向一致：攻击得手客户真实坏账率32.9%~52.9%，约为正常通过客户（11.5%）的3~5倍，说明失真现象跨数据集稳健。

## 数据来源与隐私

- Give Me Some Credit：Kaggle公开竞赛数据（匿名化，150000样本）。
- Default of Credit Card Clients：UCI公开数据集（30000样本），通过OpenML获取。
- German Credit：UCI公开数据集（1000样本）。

全部数据为公开匿名数据，本仓库代码、文档与提交记录中不包含任何真实姓名、学号或学校信息。
