# PPT上台汇报方案：分数会说谎

**汇报题目**：分数会说谎——信用评分卡的特征操纵攻防研究
**英文副题**：When Scores Lie: Feature Manipulation Attacks and Defenses in Credit Scorecards
**建议时长**：8~10分钟，14页；对应课程仓库置顶issue *FICO个人信用评分*

## 一、汇报主线（一句话故事）

一个模型指标（AUC 0.858）看起来很优秀的评分卡，却能被借款人用"申贷前突击还款"这类合法操作骗过——近半数被拒客户翻转通过，而他们的真实坏账率是正常客户的9倍。问题不在模型不够准，而在输入会被操纵。

## 二、逐页框架

**P1 封面**：标题+英文副题+GitHub仓库二维码（不放姓名、学号、学校）。

**P2 开场钩子（先抛问题）**
- 场景：两个人申请贷款，评分都是650分、都获批。一个是真优质客户，一个是申贷前一周刚把信用卡账单还清"养"出来的。
- 提问：评分卡能区分他们吗？
- 结论先行：不能。这就是今天要讲的"评分失真"。

**P3 背景：评分卡为什么是行业标准**
- FICO自1950年代起的事实标准；可解释、可审计、监管友好。
- 标准流程：分箱→WOE→IV筛选→逻辑回归→分数映射。
- 隐含前提：输入特征真实反映长期信用。

**P4 问题提出：被忽视的输入端**
- 借款人有明确操纵动机，且网上"养征信攻略"普遍存在。
- 三个研究问题：哪些特征可操纵？操纵造成多大失真？如何防御？
- 创新点：把对抗攻击的"攻击者视角"引入评分卡，而非只追求AUC。

**P5 数据与方法**
- 主数据Give Me Some Credit：150000样本、违约率6.68%；外部验证UCI台湾数据30000样本。
- 数据清洗要点：编码错误截断、winsorize、缺失填补、分层划分。

**P6 特征可操纵性分级（关键概念页）**
- 高：利用率、债务比（突击还款即可改变）。
- 中：逾期计数、收入（申诉/时间/申报）。
- 低：年龄、家属数、历史存量。
- 埋点：IV图显示预测力最强的特征恰恰是高/中可操纵特征（接P7图）。

**P7 基线评分卡表现**
- 配results/01_iv_table.png与02_score_distribution.png。
- 测试集AUC=0.858、KS=0.560、PSI=0.0004；审批通过客户坏账率1.09%，拦截91.9%坏客户。
- 强调：按传统标准，这是一张"好卡"。

**P8 攻击模型设计**
- 形式化：操纵算子T_b改变特征，但真实标签y不变。
- 四类算子：利用率、债务比、逾期洗白、收入美化，各自带操纵成本。
- 翻转客户定义：攻击前被拒、攻击后通过。

**P9 单特征攻击结果**
- 配results/03_attack_flip_curves.png。
- 利用率操纵最脆弱（满强度翻转25.8%）；逾期洗白客户真实坏账率最高（9.65%）。
- 成本-涨分曲线（04图）：低成本即可获可观涨分。

**P10 组合攻击：核心证据页**
- 配results/06_bad_rate_gap.png。
- 平均涨24分，46.1%被拒客户翻转，通过率从49.7%飙到95.6%。
- **翻转客户真实坏账率9.92% vs 正常客户1.09%，相差9.1倍**——评分失真的直接量化。

**P11 三种防御**
- 稳健评分卡：剔除高可操纵特征，翻转率46.1%→6.6%，AUC仅损失0.031。
- 突变检测：历史快照对比，强攻击检测率100%、误报1%；对新客户失效。
- 对抗训练：翻转率→36.4%，得手客户坏账率降至3.63%。

**P12 防御对比与落地建议**
- 配results/05_defense_comparison.png。
- 分层防御组合：稳健卡做底座+突变检测覆盖审批+对抗训练增强已知模式。
- 性价比排序：稳健卡>对抗训练>单纯突变检测。

**P13 外部验证与局限**
- 台湾数据结论方向一致（翻转客户坏账率32.9%~52.9%，正常客户11.5%），证明跨数据集稳健。
- 诚实交代局限：操纵成本为归一化近似、静态截面、攻防动态博弈。

**P14 结论与金句**
- 三点结论：强预测力特征可操纵；操纵可量化地制造9倍坏账；防御可低成本落地。
- 结尾金句：**"模型的准确率，回答不了输入是否诚实。风控的第一步，是承认数据会说谎。"**

## 三、答辩预案

1. **"操纵不就是正常的信用改善吗？"**
   区分点：真实改善伴随长期行为改变且真实违约率下降；本研究的操纵只改申请时点特征、标签不变，测到的9.92%坏账率证明风险未降。
2. **"为什么不直接用更复杂的模型？"**
   复杂模型同样在被操纵的输入上学习，且牺牲可解释性；实验显示问题在特征选择而非模型容量，稳健卡证据更直接。
3. **"突变检测误报会不会影响客户体验？"**
   误报仅1%，且检测结果是转人工而非直接拒贷，配合多信号叠加可进一步降低。
4. **"结论能推广到中国信贷市场吗？"**
   机制（可操纵特征+不变的真实风险）具有普遍性，外部数据集已验证；具体数值需本地数据复核，已在局限中说明。
